## 출처

- **Claude Design 산출물 URL:** https://claude.ai/artifact/YcLuwMRPM6uUn9RRHYszLs (제목 "SC-03 에이전트 바와 변경안 카드", 비공개). 로그의 `…QKN21…`은 Artifact 유형 안내(디자인 아님) [추정].
- 만든 방법: omp가 `docs/decisions/design-pty.md` 절차대로 expect로 `claude --model opus`(상태 막대 **Opus 5.5**, Claude Code 2.1.322, 창업자 결정)를 신뢰 폴더 `/tmp/kin-design-probe`에서 띄웠다. `/design`만 먼저 입력해 자동완성을 확인한 뒤 브리프 경로를 가리키는 짧은 지시를 보냈다. `Artifact(` 호출이 3분 안에 나왔다. 실행 id `sc03-20261110T223024`, `DONE.json` 실행 id 일치로 1728초(약 29분) 뒤 완료(고정 제한 없음).
- `NOTES.md`와 `DONE.json`은 Claude Design 세션이 쓴 그대로이고 omp가 고치지 않았다.

## 편차 (창업자가 수용할지 정한다)

1. 창업자 대신 omp가 만들었다(SC-01(#36) 승인 코멘트에서 수용). 모델은 Opus 5.5.
2. `preview.png`는 omp가 찍었다(헤드리스 Chrome, 임시 `--user-data-dir`, 끝나고 삭제). 맨 위 약 2400px(S1~S7 앞부분)만 보인다.
3. 글꼴: `index.html`은 외부 요청 0건, 글꼴 파일 없음. 캔버스 원본은 JetBrains Mono를 Google Fonts에서 부른다. 원장 행은 필요 없다(`scripts/check_assets.py` 통과).
4. 자기 점검 수치는 Claude Design 세션이 잰 값이다. omp는 `build_export.py`를 임시 폴더에서 돌려 `index.html`이 바이트 단위로 같게 다시 만들어지는 것을 확인했고, 조작 요소 수는 다시 세지 않았다.
5. **눈여겨볼 곳 (omp 관찰):** 브리프 0절은 S1(입력 대기)의 상시 조작 요소를 2개로 정했고 맞다. 그러나 변경안이 펼쳐진 S5·S6·S9는 `NOTES.md` 기준 조작 요소가 16개다(요약 탭, 접힌 머리 3, 값 배지 6, 행동 4, 마이크, 입력창). 브리프는 이 상태의 수를 제한하지 않았지만 "화면은 단순하게" 관점에서 승인 때 봐 달라.
6. `NOTES.md`의 [확인 필요] 항목: 수 세기 배지 없이 둔 항목 수(디자인 시스템은 `시뮬` 배지를 붙였음), 문맥 칩 위치와 탭 순서(SC-01 S10과 다름), 예산 단위(토큰, G-01이 정함). 19건의 브리프 밖 결정을 함께 봐 달라.
