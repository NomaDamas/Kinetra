## 편차 (창업자가 수용할지 정한다)

1. 창업자 대신 omp가 만들었다(SC-01(#36) 승인 코멘트에서 수용). 모델은 Opus 5.5.
2. `preview.png`는 omp가 찍었다(헤드리스 Chrome, 임시 `--user-data-dir`, 끝나고 삭제). 맨 위 약 2400px(S1~S3 일부)만 보인다.
3. 글꼴: `index.html`은 외부 요청 0건, 글꼴 파일 없음. 캔버스 원본은 JetBrains Mono를 Google Fonts에서 부른다. 원장 행은 필요 없다(`scripts/check_assets.py`는 `assets/`와 `apps/**/public/`만 보며 통과).
4. 자기 점검 수치는 Claude Design 세션이 잰 값이다. omp는 `build_export.py`를 임시 폴더에서 돌려 `index.html`이 바이트 단위로 같게 다시 만들어지는 것을 확인했고, 조작 요소 수는 다시 세지 않았다. S1은 8개(브리프 5.1절 이름 그대로), 카드 안 `primary` 0이라고 `NOTES.md`가 적었다. 승인 때 눈으로 세 주기 바란다.
5. **브리프와 달리 쓴 라벨(시안의 문구 변경):** 민감도 줄 이름을 디자인 시스템의 "민감도 · 판정을 뒤집는 가정" 대신 "민감도 1위 · 확률을 가장 크게 바꾼 가정"으로 썼다. 시연의 두 결과가 모두 `FEASIBLE_FOUND`라 판정 코드가 바뀌지 않기 때문이다(D0-02c 리뷰 지적과 브리프 4절을 따름). 판정 코드가 실제로 바뀌는 민감도가 나오면 원래 라벨로 돌릴 수 있다.
6. `NOTES.md`가 [제안]·[확인 필요]로 적은 브리프 밖 결정 16건을 함께 봐 달라. 예: 단위·배지 규칙의 예외(개수 표시 "가정 4개", 신뢰구간 막대 눈금은 UI 라벨로 보고 배지 없음), 넷째 가정을 "행성 상수 · 지구 · `인용`"으로 한 것, 예산 이름 빠르게/보통/넉넉히, S12 패널과 타임라인의 위아래가 셸과 반대인 점.
