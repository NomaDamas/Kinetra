셸 안의 위치: SC-01 왼쪽 패널

SC-01 셸의 왼쪽 패널(240 × 790 px) 안을 채웁니다. 머리, 접기, 탭 묶음의 자리와 모양은 SC-01 그대로입니다. 모드의 primary는 SC-01 상단바에 있고, 이 패널에는 primary가 없습니다.

상시 조작 6개(4.1절)

  1. 패널 접기
  2. 탭 묶음(기본 부품 · 내 것)
  3. 정렬 선택(출처 먼저)
  4. 필터 버튼(적용 0)
  5. 부품 목록(줄 선택 · 끌기)
  6. 값 배지 열(줄마다 근거 팝오버)

줄 하나 = 2D 썸네일 · 이름 · 종류 · 값 · 단위 · 값 배지. 배지는 오른쪽 열에 모입니다. 줄 전체와 왼쪽 손잡이가 끌기의 시작점입니다(놓는 곳인 뷰포트는 범위 밖).

기본 정렬의 줄 값은 그 부품의 대표 사양입니다. 냉가스 추력기는 최대 추력 8.9 N 인용(design-system.md 10절), 나머지는 질량이고 모두 예시입니다 [확인 필요: 2절은 기본 정렬도 질량].

값이 없는 줄(고정 결합)은 정의 없음으로 맨 뒤에 둡니다. 아래 4개는 스크롤하면 보입니다.

펼친 줄에 있는 것

  • 2D 개략도: 윤곽 + 치수선. 치수도 값 · 단위 · 배지입니다.
  • 사양 행: 줄에 이미 보인 값은 다시 쓰지 않습니다(같은 정보 두 번 금지). (a)의 최대 추력 8.9 N은 줄에만 있습니다.
  • 출처와 라이선스 한 줄. 인용 부품은 카탈로그 항목, 파라메트릭 부품은 시스템 기본값 표의 항목입니다.
  • 작업대에 추가(secondary): 끌어 놓기의 대안입니다. 끌어 놓기 안내 한 줄을 함께 둡니다.

다른 줄을 펼치면 이 줄은 접힙니다. Esc나 같은 줄을 다시 누르면 접힙니다. prefers-reduced-motion이면 펼침은 불투명도 전환만 씁니다.

정렬 규칙(L-04)

  • 출처 먼저(기본): 인용 → 기본값 → 사용자 선언 → 시뮬 → 추정, 같은 출처 안에서 종류 → 이름 [제안]. 출처 묶음마다 머리 글자를 둡니다.

필터(L-04)

  • 종류 6가지와 값 배지 4종(인용 사용자 선언 기본값 추정). 배지 선택지는 값 배지 모양 그대로 그립니다(글리프 · 라벨 · 테두리).
  • 같은 묶음 안은 "또는", 묶음 사이는 "그리고"입니다 [제안].
  • 고르는 즉시 목록에 반영합니다. 적용 버튼이 없습니다. 결과 개수는 스크린리더에 읽어 줍니다.

  • 배지 필터가 켜지면 값 배지 열 머리가 강조됩니다(배지 · 기본값).
  • 해제: 팝오버의 해제, 또는 목록 맨 위 해제 줄. 정렬은 그대로 둡니다.

셸 안의 위치: SC-01 왼쪽 패널의 값 배지 열

값 배지는 design-system.md 4절 그대로입니다: 글리프 + 라벨 + 테두리 모양. 색은 출처 종류만 말합니다. 증거 색(보라)과 상태 색을 배지에 쓰지 않습니다.

키보드: 줄에서 →로 그 줄의 배지, Enter로 팝오버, Esc로 닫고 줄로 돌아갑니다 [제안].

hover는 면을 한 단계 밝히고, 포커스는 2 px 링 + 2 px 간격, 팝오버 열림은 배지 글자색의 1 px 링입니다.

근거 조회는 어느 화면에서도 막지 않습니다(V1). 읽기 전용 화면에서도 배지 포커스와 팝오버는 그대로입니다.
