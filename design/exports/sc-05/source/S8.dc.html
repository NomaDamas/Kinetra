S8 내 조립체 저장 · 선택한 조립체 저장을 누르면 패널 안에 인라인 카드(모달 아님). (a) 이름 입력 (b) 이름 비었음 거부 (c) 이름 중복 거부 (d) 저장 뒤 새 줄 + 토스트카드 안 조작 3 + 값 배지 · primary 0
셸 안의 위치: SC-01 왼쪽 패널 · 내 것 탭

카드에 있는 것

  • 이름 입력(처음에 포커스).
  • 요약: 부품 수, 보존하는 결합 수, 질량 합. 엔진이 센 값이라 모두 시뮬입니다.
  • 저장(secondary), 취소(ghost). 패널에 primary가 없습니다.

검증 거부: 이름 비었음, 같은 이름. 입력 테두리 color.status.danger + 이유 한 줄. 입력한 값은 남습니다.

저장 뒤: 카드가 닫히고 새 줄이 시뮬 묶음 맨 위에 불투명도 전환 한 번으로 들어옵니다. 토스트 "내 것에 저장했습니다" + 되돌리기. 토스트는 포커스를 빼앗지 않습니다.

결합은 그대로 보존됩니다(L-01b). 수치는 예시, 질량 합 1.3 t는 S7과 같은 [확인 필요]입니다.
