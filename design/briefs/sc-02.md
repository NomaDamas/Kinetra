## 0. 창업자 지시: 하드 제약 (모든 화면에 적용, 2026-11-10, #33 승인 코멘트)

> **기능은 빠짐없이, 화면은 단순하게.** 기본 화면에는 주 행동 하나와 필요한 정보만 보이고, 나머지 기능은 단계적으로 드러낸다(진행형 공개). 인지부하를 최소로 한다.

어긴 아트보드는 승인하지 않는다.

1. **기능을 빼서 단순하게 만들지 않는다.** 3절의 필드 목록 전부가 최대 2단계(펼침·탭 선택 두 번) 안에서 닿는다.
2. **기본 화면(S1: 강체 하나를 선택한 인스펙터)의 상시 조작 요소는 10개 이하**이고 5.1절에 이름을 못 박았다. 세는 법(SC-01 브리프 0절 2번과 같다): 버튼, 입력 필드, 선택 컨트롤, 접기·펼치기 머리, 누를 수 있는 값 배지가 각각 1이다. 읽기 전용 글자, 단위, 구분선은 세지 않는다. 패널 바깥(상단바, 에이전트 바 등)은 세지 않는다.
3. **이 패널에 `primary` 버튼은 없다.** 화면의 `primary`는 상단바의 모드 주 행동 하나이고 인스펙터는 건드리지 않는다. 값을 고치는 일은 입력과 Enter, 되돌리기 한 줄로 끝난다(저장 버튼 없음) [제안].
4. **진행형 공개:** 한 번에 한 가지 수준만 연다. 기본은 "이 부품이 무엇이고 무겁기가 얼마인가"까지다. 관성, 한계, 파단 임계, 곡선처럼 자주 안 쓰는 것은 접힌 머리 뒤에 있고 머리를 누르면 한 번에 하나만 열린다(아코디언) [제안]. 숨은 것은 접힌 머리의 이름과 개수 요약("관절 2")으로 존재가 보인다.
5. **한 패널에 제목 하나, 열린 섹션은 하나.** 같은 값을 두 곳에 반복하지 않는다.
6. **정직성 표시는 단순함을 이유로 줄이지 않는다.** 보이는 모든 수치에는 단위와 값 배지가 붙는다. 값 배지는 접힌 요약 줄에도 남는다.

### 자기 점검 (Claude Design이 끝에 표로 보고)

| 점검 | 기준 |
|---|---|
| 상시 조작 요소 수 | 아트보드마다. S1은 10 이하이고 5.1절의 이름과 일치 |
| `primary` 버튼 수 | 인스펙터 안에 0. 상단바가 그려진 아트보드에서는 정확히 1 |
| 단계 | 3절 필드 목록의 모든 행이 0·1·2단계 중 어디서 닿는지. 2 초과 없음 |
| 배지 | 5종이 모두 어느 아트보드에 있는지. 단위나 배지 없는 수치 0건 |
| 금지 | 새 색 토큰 0. 초록 성공·빨강 실패 없음(`status.danger`는 입력 검증 거부 테두리에만). 금지 문구 0건 |

## 1. 대목표와 핵심 가치

대목표 G0: 모든 작업이 대목표·핵심 가치·계획에 묶여 한 번에 100% 끝나는 루프를 만든다. 인스펙터는 G1(상상한 물건을 만들어 정직한 판정이 붙은 Halo로 내보낸다)에서 사용자가 "이 부품의 이 수치는 어디서 왔는가"를 보는 곳이다. 이 화면이 없으면 B-06 인스펙터 구현이 참조할 승인된 디자인이 없다.

> **V1 정직한 판정** — 판정은 시뮬과 몬테카를로만 한다. 확률, 가정, 한계를 숨기지 않는다. 1회 미리보기 실행을 판정이라 부르지 않는다.

> **V2 상상에서 현실까지** — 모든 기능은 생각 → 상상 → 실제 물리 세계의 거리를 줄여야 한다.

V1은 모든 수치에 값 배지(출처)를 붙이는 것으로, V2는 값을 고치면 질량·무게중심이 바로 갱신되는 것으로 나타난다. (V5 깨끗한 출처의 값 배지 규칙도 따른다: `design-system.md` 4절.)

## 2. 구조

```
┌ 인스펙터 ─────────────── 접기 ┐   320 px 패널(셸 오른쪽). 접힘은 40 px 레일.
│ 차체  · 강체                  │   제목: 선택 이름 + 종류 한 줄
├───────────────────────────────┤
│ 질량     1.3 t   [사용자 선언] │   ← 열린 섹션 "강체"의 기본 줄들
│ 재질     [프리셋 ▾] [인용]     │
│ 질량중심 x y z m  [시뮬]       │   (계산값, 읽기 전용)
│ ▸ 관성 보기                    │
├───────────────────────────────┤
│ ▸ 재질 세부                    │   접힌 섹션 머리들(아코디언)
│ ▸ 관절 2                       │
│ ▸ 액추에이터 1                 │
└───────────────────────────────┘
```

- 한 번에 **선택 종류에 맞는 섹션만** 보인다: 강체를 고르면 [강체, 재질 세부, 연결된 관절, 연결된 액추에이터], 관절을 고르면 [관절, 연결된 두 강체], 액추에이터를 고르면 [액추에이터, 붙은 강체]. 선택한 것의 섹션이 열려 있다. 선택을 바꾸면 열림 상태는 처음으로 돌아간다 [제안].
- 필드 행은 디자인 시스템의 인스펙터 필드 행(라벨 · 값(`type.mono`) · 단위 · 값 배지)을 그대로 쓴다. 높이 `size.control.md`. 새 행 변형을 만들지 않는다.
- 값 입력: 값 칸에서 Enter로 확정, Esc로 취소, 확정하면 필드 아래에 "이전 → 새 값"과 `되돌리기`가 한 줄 나타나고 5초 뒤 접힌다(되돌리기 단축키는 SC-01의 `⋯` 메뉴) [제안]. 값을 덮어쓰면 배지가 `사용자 선언`으로 바뀐다(`design-system.md` 4절).
- 검증 거부: 규칙에 어긋난 값은 저장하지 않고 필드에 `color.status.danger` 테두리 + 이유 한 줄("질량은 0보다 커야 합니다. 값을 저장하지 않았습니다"). 이 색은 입력 검증 거부에만 쓴다(5.2절).
- **계산값과 선언값의 구분**(4.4절): 강체의 질량·무게중심·관성은 부품 형상과 재질에서 엔진이 **계산한 값**(`시뮬`, 읽기 전용)이거나 사용자가 **선언한 값**(`사용자 선언`)이다. 질량 행에 `계산값 | 선언값` 두 상태가 있고 전환은 질량 값 칸을 직접 고치는 것으로 한다(고치면 선언값, `선언 해제`로 계산값으로 돌아감) [제안].

| 관절 | 파단 임계 | 2 | `기본값` / `인용` | 항상 "단순화 모델" 라벨(4.6절): 결합부 임계값이지 정밀 해석이 아님 |

| 액추에이터 | 추력 곡선 또는 토크-속도 곡선 | 2 | `인용` / `사용자 선언` | 곡선은 작은 표 + 선 그림. 편집은 표 |
| 액추에이터 | 추진제 질량 | 2 | `사용자 선언` | 단위 kg |
| 액추에이터 | 제어 스케줄 | 2 | `추정`(에이전트 초안) | 시간–값 표. 에이전트가 낸 초안이면 점선 필드 + `추정`, 수락해야 확정 |
| 선택 없음 | — | — | — | 5.2의 S5 |
| 다중 선택 | 공통 필드 | 0 | 섞이면 `—` | 편집은 선택한 모두에 적용된다고 한 줄로 알림 |

모든 필드는 2단계 안에 닿는다. 3단계 이상 깊은 필드는 없다.

## 4. 정직성 규칙

- 모든 수치: 값 · 단위 · 값 배지. 무차원 값은 단위 자리에 `–`. 배지 5종(`시뮬`, `인용`, `기본값`, `사용자 선언`, `추정`)이 이 화면의 아트보드에 모두 나온다. 배지를 누르면 근거 팝오버(`인용`: 출처와 라이선스, `시뮬`: 어떤 계산에서 나왔는지, `사용자 선언`: 선언한 사람과 시각, `추정`: 추정 방법, `기본값`: 기본값의 출처). 읽기 전용 상태에서도 배지는 눌린다.
- `인용` 배지의 출처는 지어내지 않는다. 예시는 `design-system.md` 10절의 값(차체 질량 1.3 t `사용자 선언`, 냉가스 추력기 카탈로그 최대 추력 8.9 N `인용`, 노즐당 추력 8 kN `카탈로그 밖 · 사용자 선언`)과 `예시` 꼬리표가 붙은 것만 쓴다. 재질 프리셋 이름과 밀도·마찰 수치는 지어내지 않고 `예시`를 붙이거나 이름 자리를 "재질 프리셋 A(예시)"처럼 쓴다.
- 파단 임계는 항상 "단순화 모델" 라벨과 함께 보인다. FEM, 정밀 해석처럼 말하지 않는다.
- 에이전트가 낸 값(제어 스케줄 초안, 프록시 질량)은 점선 필드 + `추정` 배지이고 사용자가 수락하기 전에는 모델에 반영되지 않는다. 에이전트가 값을 확정하거나 판정을 말하지 않는다(`design-system.md` 9절).
- 엔진 연결이 끊기면 계산값(`시뮬`)에 "오래됨 · 마지막 계산 시각"을 붙이고 새로 계산한 값처럼 보이지 않게 한다. 선언값은 그대로 고칠 수 있다 [확인 필요: 끊긴 동안 어떤 편집이 되는지는 A0-04가 정한다].
- 증거 단계 색은 이 패널에 쓰지 않는다(수치의 출처 배지와 증거 단계는 다른 축이다).

| S5 | 선택 없음 | 패널은 열려 있다. 빈 화면: `type.heading` 한 줄("선택한 부품이 없습니다") + 설명 한 줄(뷰포트에서 부품을 고릅니다) + 다음 행동 하나(없으면 생략). 조작 요소 1개(접기) |
| S6 | 다중 선택 | 부품 3개를 선택. 같은 값은 그대로, 다르면 `—`와 배지 자리 `섞임`(배지가 아니라 읽기 전용 글자). "3개에 적용됩니다" 한 줄 |
| S7 | 값 편집 상태 | 같은 패널에서 행별 상태 한 줄씩: 편집 중, 바뀜(이전 → 새 값 + 덮어쓰면 배지가 `사용자 선언`으로), 검증 거부(`status.danger` 테두리 + 이유), 에이전트 제안(점선 + `추정`), 계산값(읽기 전용) |
| S8 | 읽기 전용·오래됨 | (a) 실행 모드: 값 칸 잠금, 배지는 눌림. (b) 엔진 오프라인: `시뮬` 값에 "오래됨 · 마지막 계산 시각 [예시]" |
| S9 | 값 배지 5종 팝오버 | 5종 각각의 근거 팝오버 한 장씩(한 아트보드에 5개 나란히). 출처는 지어낸 이름 대신 "출처 이름(예시)" 같은 자리 표시 |
| S10 | 키보드 | S1 위에 탭 순서 번호(접기 → 질량 → 질량 배지 → 재질 → 재질 배지 → 질량중심 배지 → 관성 → 머리 3개)와 포커스 링 예, 화살표 키로 머리 사이 이동 주석 |

## 6. 규칙

- 패널은 뷰포트보다 조용하다. `elevation.1`. 장식·일러스트 없음.
- 모든 텍스트 대비 4.5:1, 비문자 3:1, 누르는 영역 24×24 px 이상. 포커스 링 2 px `color.focus.ring` + 2 px 간격. `prefers-reduced-motion`이면 섹션 접힘·펼침은 불투명도 전환만.
- 키보드: 모든 입력·머리·배지에 Tab으로 닿는다. 머리는 Enter/Space로 열고 닫는다. `Esc`는 열린 팝오버·편집을 닫는다.
- 금지 문구: `design-system.md` 9절 전체. 특히 "현실과 동일", 에이전트가 값을 "확정했다"는 문구, 파단을 정밀 해석처럼 말하기.
- 색은 `tokens.json`에 있는 값만. 새 색 토큰 금지. 초록 성공·빨강 실패 금지.

## 7. 이 브리프가 정하지 않는 것

판정 카드와 가정표(SC-04), 에이전트 바·변경안 카드(SC-03), 질량중심·지지 다각형 오버레이와 기즈모(코드 프로토타입), 라이브러리와 가져오기 마법사(SC-05), 재질 프리셋의 실제 목록과 수치(B-06b, 출처 필요), 관절 종류의 전체 목록(B-06c), 엔진 오프라인 중 편집 규칙(A0-04), XR 인스펙터 요약(SC-11).
