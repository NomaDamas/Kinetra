# SC-02 수정 지시 (리뷰 반영, #411)

> 대상: `design/briefs/sc-02.md`로 만든 Claude Design 산출물(artifact https://claude.ai/artifact/W5F2kNGaJAdKUv1nBEhgdP, 내보내기 `design/exports/sc-02/`). 아래 네 가지만 고친다. 다른 아트보드·문구·값은 바꾸지 않는다. 브리프 0절(창업자 지시: 기능은 빠짐없이, 화면은 단순하게, 진행형 공개)과 `design-system.md` 9절 금지 문구는 그대로 적용된다.

1. **관절 축 입력의 기준 좌표계.** S3(관절)의 축 x·y·z 단위 벡터 옆에 기준 좌표계를 보여 준다. 예: 라벨 "부모 바디 좌표계 기준"(또는 로컬/월드 선택 컨트롤). 선택 컨트롤을 쓰면 상시 조작 요소 수(S3)와 `NOTES.md`의 표를 갱신하고, 읽기 전용 라벨이면 수에 넣지 않는다. 어느 쪽이든 단위 벡터 값에는 단위 자리 `–`와 배지가 그대로 있다.
2. **S4 액추에이터의 최대 추력과 노즐당 추력 모순 제거.** 지금은 "최대 추력 8.9 N"과 "노즐당 추력 8 kN"이 동시에 유효한 값처럼 나란히 있다. 하나의 출처만 진실이 되게 한다. 두 개념이 다르면(카탈로그 사양의 최대 추력 8.9 N `인용` 대 이 설계에서 사용자가 선언한 노즐당 추력 8 kN `카탈로그 밖 · 사용자 선언`) 서로 다른 이름으로 일관되게 표시하고, 선언값이 카탈로그 사양을 넘는다는 사실이 한 줄로 보이게 한다(카탈로그 밖). 예시 값은 `design-system.md` 10절의 값만 쓴다. S2 (d)와 S4의 모든 변형에서 같은 이름과 값을 쓴다.
3. **관절 선택에서 한계와 파단 임계가 한꺼번에 열려 있음.** 진행형 공개 하드 제약(브리프 0절 4번) 위반이다. 관절을 선택하면 종류와 요약(한계 요약 한 줄, 파단 임계 요약 한 줄, 각각 값 · 단위 · 배지)만 보이고, 축·한계·파단 임계의 상세는 접힌 머리 뒤에 둔다(한 번에 하나만 열림). 상세에 도달하는 단계는 2 이하를 유지한다. S3 한 장으로 접힌 상태를, 필요하면 한 장 더 펼친 상태를 보인다. 파단 임계에는 "단순화 모델" 라벨이 그대로 있다.
4. **S7 질량중심 행의 넘침.** 질량중심 x y z 벡터와 잠금 아이콘이 320 px 패널의 값 칸을 넘친다. 값 칸 안에 들어오게 한다(줄바꿈 또는 축약 표기, 예: 세 값을 좁은 입력 셋으로 나누거나 x/y/z를 두 줄로). 같은 행이 있는 다른 아트보드(S1, S2, S6, S10)도 같은 방식으로 맞춰 일관되게 한다. 패널 밖으로 넘치는 요소 0건, 누르는 영역 24×24 px 이상 유지.
