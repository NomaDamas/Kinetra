# SC-02 수정 지시 2 (리뷰 2차 반영, #411)

> 대상: 현재 `design/exports/sc-02/`(artifact https://claude.ai/artifact/W5F2kNGaJAdKUv1nBEhgdP, 첫 수정까지 반영됨). 아래 네 가지만 고친다. 다른 아트보드·문구·값은 바꾸지 않는다. 브리프 0절(창업자 지시: 기능은 빠짐없이, 화면은 단순하게, 진행형 공개)과 `design-system.md` 9절 금지 문구는 그대로 적용된다. `NOTES.md`는 이번에 고친 것뿐 아니라 **유지한 설계 결정**도 "유지한 것" 절에 결정 내용 그대로 다시 적는다(어느 결정을 왜 유지했는지, "그대로"라고만 쓰지 않는다).

1. **질량중심 x·y·z의 기준 좌표계.** 질량중심 행(S1, S2, S6, S7, S8, S9, S10 모두)에 기준 좌표계를 읽기 전용 글자로 보인다. 예: "조립체 원점 기준"(또는 이 부품이 강체이면 "부모 바디 좌표계 기준"). 어느 쪽을 쓰든 값 · 단위 · 배지는 그대로이고 조작 요소 수와 S1의 10개 이름은 바꾸지 않는다. 관절 축의 기준 좌표계 라벨(S3)과 같은 표기 방식을 쓴다.
2. **질량중심 칸이 현실적인 값을 담는다.** 지금 칸 하나는 37 px라 4자(`0.12`)만 들어가고 5자 이상(`-0.45`, `12.30`)은 안 들어간다고 `NOTES.md`가 적었다. 부호 포함 6자 이상의 값(예: `-12.35 m`)이 들어가도록 칸 폭을 넓히거나 축마다 한 줄(x/y/z 세 줄)로 내린다. 예시 값에 `-12.35`와 `0.12`를 둘 다 넣어 보여 주고, 넘침 0건(패널 밖, 칸 밖, 찌그러진 아이콘)을 측정으로 확인한다. 행이 늘면 S1 패널이 790 px 안에 들어오는지도 확인한다.
3. **S2 (d) 고정 높이 패널에서 펼친 내용이 잘림.** 패널 높이 790이 고정인데 액추에이터를 펼치면 내용이 넘친다. 패널 본문에 세로 스크롤(스크롤 영역)을 두고 머리(제목 줄)는 고정한다. 접힌 머리의 이름과 개수가 스크롤 아래에서도 보이게 한다(SC-04 S2와 같은 방식: 접힌 머리를 본문 아래쪽에 붙임). S4의 펼친 변형도 같은 방식으로 맞춘다.
4. 위 1~3을 반영한 뒤 S1의 상시 조작 요소 10개와 이름, 카드 안 `primary` 0, 새 색 0, 배지 5종 위치를 다시 측정해 `NOTES.md`의 자기 점검 표를 갱신한다.
