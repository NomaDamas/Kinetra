# 클린룸 관찰 기록: Kerbal Space Program (KSP)

> 이 기록은 `docs/process/rea-policy.md`의 클린룸 방식을 따른다. 독점 제품은 **밖에서만** 봤다. 디컴파일, 에셋 추출, 데이터 복제, DRM 우회를 하지 않았고, 이 기록에는 원문 긴 인용, 스크린샷, 영상 프레임, 에셋, 부품 수치표가 없다.
> 구현은 이 기록만 보고 한다. 이 기록의 항목 번호(A1, B3 …)를 구현 PR 본문에 링크한다.

## 1. 관찰 방법

- [ ] 직접 플레이·사용: **하지 않았다.** 이 기록의 `추정`은 플레이에서 잰 값이 아니라 공개 문서를 읽고 우리가 한 해석이다. 창업자 플레이 관찰은 이슈 범위 밖이고, 원하면 `추정` 값으로 이 문서 뒤에 덧붙인다.
- [x] 공개 문서 (모두 2026-11-11에 읽음):
  - KSP 공식 위키(`wiki.kerbalspaceprogram.com`, 첫 화면이 스스로를 공식 커뮤니티 위키라고 소개한다): VAB 편집기, 무게중심, 추력중심, 스테이징, 엔지니어 보고서, 흔들림, 시간 가속, 대기, 잔해, 회수, 치명적 실패, 커리어, 계약, 서브어셈블리, 액션 그룹, 크래프트 공유, 애드온, 버전 기록(1.0·1.2 변경 목록 포함), KSP 2 문서, 우주인 단지, 추적소, 튜토리얼 목록·게임 매뉴얼 등. 이 쪽들에서는 **설명 문장과 규칙**을 읽었다.
  - **열람했으나 근거로 쓰지 않은 쪽**: 부품 목록·부품 정의 파일 내용·기술 트리 부품표·과학 배율표를 옮겨 놓은 위키 쪽(`Parts`, `Technology_tree`, `Science`, `EAS-4_Strut_Connector`, `Physicsless_part`). 이 쪽들은 정책이 막는 게임 데이터(부품 수치, 부품 설정 값, 밸런스 표)를 담고 있어서, 이 기록의 어떤 항목도 이 쪽들을 근거로 하지 않는다. 이 쪽들에서만 나온 내용(스트럿이 강체 연결로 거동한다는 서술, 오토스트럿의 연결 대상 프리셋, 물리 없는 부품, 부품 속성 목록, 과학 상황·바이옴 구조, 기술 트리 단 수)은 초안에서 **뺐다**.
  - 이 기록에는 게임의 설정 값(물리 범위 거리, 대기 밀도 문턱, 추적 개체 상한, 부품 수 상한의 숫자, 행성 상수)을 옮기지 않았다. 숫자는 공개 문서의 시각표(KSP 1.0 공개일 등)와 시간 가속 단계처럼 사용자에게 보이는 화면 규칙만 남겼다.
  - 상점 소개글: Steam의 KSP 1 `https://store.steampowered.com/app/220200/Kerbal_Space_Program/`, KSP 2 `https://store.steampowered.com/app/954850/Kerbal_Space_Program_2/`.
  - 보도·백과: 위키백과 `https://en.wikipedia.org/wiki/Kerbal_Space_Program`, `https://en.wikipedia.org/wiki/Kerbal_Space_Program_2`, Polygon `https://www.polygon.com/23612194/kerbal-space-program-2-early-access-release-date-impressions/`, Space.com `https://www.space.com/kerbal-space-program-2-update-for-science`.
- [ ] 개발자 발표·블로그: **직접 읽지 못했다.** 공식 포럼(`forum.kerbalspaceprogram.com`)과 Epic 소식 페이지는 봇 차단(HTTP 403)이라 열리지 않았고, **우회하지 않았다.** 그 글들의 내용은 상점 소개글, Space.com 기사, 위키의 요약을 거친 것만 썼고 그렇게 표시했다.

## 2. 하지 않은 일

- [x] 독점 바이너리·어셈블리·번들을 열거나 디컴파일하지 않았다. 게임을 설치하거나 실행하지도 않았다
- [x] 에셋(모델, 텍스처, 소리, UI)을 꺼내지 않았다. 위키 쪽의 그림과 스크린샷은 보지도, 저장하지도 않았다
- [x] 부품 수치·상수·형식 명세를 추출하거나 자동 수집하지 않았다. 부품 목록 표와 부품 설정 값을 옮겨 놓은 위키 쪽(1절 목록)은 근거로 쓰지 않았고 거기서 온 내용은 이 기록에서 뺐다. 이 기록에 부품 하나의 질량, 추력, 비용, 강도, 설정 값은 없다
- [x] DRM·라이선스·접근 제어를 우회하지 않았다
- [x] 이 기록을 쓰는 사람이 풀어 본 코드를 곁에 두고 있지 않다

**확인 문장.** 이 기록을 쓰면서 REA(`morluto/rea`)를 쓰지 않았다. KSP의 어셈블리, 세이브, 크래프트 파일, 부품 설정 파일, 모드 파일을 열거나 풀거나 분석하지 않았고(위키가 옮겨 적은 설정 값 쪽도 쓰지 않았다),, 게임 데이터를 캐거나(데이터마이닝) 자동으로 모으지 않았다. 도구는 공개 웹 페이지 읽기(`read`)와 웹 검색(`web_search`)뿐이다. KSP 2가 "게임 파일에서 알아낸" 정보라고 밝힌 출처(위키가 각주로 인용한 커뮤니티 게시글 등)는 읽지도 쓰지도 않았다. 상표·특허와 표현의 경계는 법률 자문이 아니며 [확인 필요]다.
