# Kinetra 핵심 가치

단일 원본이다. 모든 이슈와 PR은 이 문장을 그대로 인용한다. 원문은 `docs/plan/studio-plan.md` 1절과 글자 단위로 같아야 한다.

- **V1 정직한 판정** — 판정은 시뮬과 몬테카를로만 한다. 확률, 가정, 한계를 숨기지 않는다. 1회 미리보기 실행을 판정이라 부르지 않는다.
- **V2 상상에서 현실까지** — 모든 기능은 생각 → 상상 → 실제 물리 세계의 거리를 줄여야 한다.
- **V3 한 번에 100%** — 작은 단위를 증거와 함께 완전히 끝낸다. 부분 완성은 미완성이다.
- **V4 보여줄 수 있는 결과** — 결과는 시뮬 리플레이 그대로 영상과 플레이 링크가 된다. 연출은 카메라·조명·편집만 바꾸고 궤적은 바꾸지 않는다.
- **V5 깨끗한 출처** — 수치, 부품, 에셋은 출처와 라이선스가 기록된 것만 쓴다. 사용자가 선언한 값과 가져온 에셋은 배지로 구분한다.

## 대목표

- **G0** 모든 작업이 대목표·핵심 가치·계획에 묶여 한 번에 100% 끝나는 루프를 만든다.
- **G1** 창업자가 세 행성 어디서든 상상한 물건을 만들어 정직한 판정이 붙은 Halo로 내보낸다.
- **G2** 같은 프로젝트에 목표와 규칙을 얹어 미션과 게임, 열린 세계로 넓힌다.
- **G3** 만화 장면이 실제로 되는지 필요조건과 에너지로 답한다.
- **G4** 설계로 겨루고 함께 짓고 부순다.
- **G5** 시뮬에서 된 설계가 실물 키트로 이어지고 실측이 판정을 보정한다.
- **G6** 물·바다·유체가 있는 장면도 근사의 등급을 밝힌 채 만들고 돌려 본다.
